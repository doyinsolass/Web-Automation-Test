# Python Learning Starter

This repository now contains a simple Python learning setup with:

- one beginner-friendly module
- one unit test file using `unittest`
- clear run commands

## Requirements

- Python 3.10+

## Files

- `python_learning.py` — simple functions for practice
- `test_python_learning.py` — tests for those functions

## Run the code

```sh
python python_learning.py
```

## Run the tests

```sh
python -m unittest test_python_learning.py
```

## What to practice next

- Change return values and see which tests fail
- Add a new function in `python_learning.py`
- Add a matching test in `test_python_learning.py`
